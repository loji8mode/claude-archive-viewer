# Claude Archive Smart Viewer

Утиліта на Python для перетворення стандартного експорту діалогів Claude AI (з файлу `conversations.json`) у локальний інтерактивний веб-інтерфейс.

## Особливості
* **Візуалізація думок (Thinking):** Згортає довгі блоки міркувань моделі у клікабельні блоки.
* **Підтримка артефактів:** Рендерить HTML/SVG артефакти всередині ізольованих `iframe` із можливістю перегляду сирого коду та скачування.
* **Темна тема:** Інтерфейс адаптовано під комфортне читання вночі.
* **Автономність:** Весь результат зберігається в один єдиний HTML-файл, який працює без інтернету.

## Використання

1. Покладіть ваш експортований файл `conversations.json` в одну папку зі скриптом.
2. Запустіть скрипт:
   ```bash
   python extractor.py
3. Відкрийте згенерований файл viewer.html у будь-якому браузері.
